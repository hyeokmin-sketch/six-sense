## 1. 목표와 범위

- **목표:** 경상도 사투리 음성 → 사투리 그대로의 텍스트 (표준어 변환·명령 생성은 LLM 담당)
- **모델:** 특강에서 지정한 SenseVoice. 보드는 sherpa-onnx int8 ONNX, 학습은 PyTorch 원본 SenseVoiceSmall
- **범위:** 사투리는 경상도만, 기기는 블라인드·조명·에어컨, 출력 언어는 한국어·영어만

## 2. 지금까지 한 것

1. **데이터셋:** `SIX-SENSE_ABC_데이터셋_경상도.xlsx` — 307문장(A 경상도 177 / B 모호한 표준어 75 / C 감정 55). STT 학습에는 A 178문장(예시 1개 포함)만 사용
2. **학습 음성:** A 문장을 한국어 TTS로 6가지 변형 합성 → 1,068개 (학습 142문장 852개 / 검증 36문장 216개, 문장 단위로 분리)
3. **파인튜닝:** SenseVoiceSmall 10 epoch(약 6분, RTX 4060) → 검증 CER 최저 epoch 9 선택
4. **보드용 변환:** int8 ONNX + 한국어·영어 출력 마스크 → `models/sense-voice-ko-tts_a1/` (239MB). 원본과 파일 이름·입출력 형식이 같아 파일만 교체하면 됨
5. **평가셋 추가:** 엑셀에 없는 새 문장 60개 × TTS 2변형 = 120개 (`학습데이터/unseen/`, 학습 금지 고정 평가셋)

## 3. 성능 결과

CER = 글자 오류율(낮을수록 좋음). 공백·문장부호는 빼고 계산.

| 평가 데이터 | 개수 | 원본 CER | **tts_a1 CER** | tts_a1 완전일치 |
|---|---|---|---|---|
| 학습에 쓴 문장 | 852 | 41.1% | **5.2%** | 64.6% |
| 검증 문장 (엑셀에 있으나 학습 안 함) | 216 | 42.0% | **19.0%** | 23.6% |
| 처음 보는 문장 전체 | 120 | 38.0% | **22.0%** | 20.0% |
| └ 경상도 기기 명령 (새 표현) | 60 | 44.0% | 22.5% | 11.7% |
| └ 경상도 일상 대화 | 30 | 47.1% | 33.8% | 6.7% |
| └ 표준어 | 30 | 15.2% | 11.2% | 50.0% |
| 실제 녹음 (본인 1명) | 7 | 56.8% | **2.3%** | 6/7 |

- 실제 녹음 7개 중 학습 문장 2개, 검증 문장 5개. 검증 문장 5개만 보면 원본 48.5% → tts_a1 3.0%
- 한국어·영어 마스크만 붙인 모델(ko-en)은 TTS 음성에서는 원본과 같고, 실제 녹음에서는 47.7%

### 해석
- **사투리 인식은 확실히 좋아짐:** 처음 보는 경상도 기기 명령도 오류가 절반(44% → 22.5%)
- **문장을 외운 효과가 큼:** 학습 문장 5% vs 처음 보는 문장 22% → 178문장은 부족
- **기기와 무관한 사투리는 약함(33.8%):** 학습에 없던 어휘("뭇나", "단디")는 거의 못 알아들음
- **표준어는 나빠지지 않음(15.2% → 11.2%):** 다만 개별 퇴행 사례 있음("오늘 날씨 어때" → "오늘 안 쉬 어")

### 한계
- 학습·평가 음성이 모두 **같은 TTS 목소리(표준 억양 1명)** → 실제 경상도 화자 성능은 더 낮을 가능성이 큼
- 실제 녹음은 1명·7문장뿐이라 수치 신뢰도가 낮음
- 학습 정답에 문장부호가 없어 출력에서 마침표가 사라짐

## 4. 참고 문서 검토에서 나온 확인 사항

| # | 내용 | 확인 대상 |
|---|---|---|
| 1 | 특강 34쪽 "전 팀 동일 모델" → 파인튜닝한 STT로 바꿔 써도 되는지 | 멘토 |
| 2 | 수행계획서에는 김용희 = 앱·IoT 연동, STT = 김형균으로 적혀 있음 → 역할 변경 반영 필요 | 팀 |
| 3 | 마음AI HomeIoT 데이터 시트 기기 목록(오븐·욕조·에어컨·청소기·커피머신·블라인드·냉장고)에 **조명 없음** → 올해 플랫폼에서 조명 지원 여부 | 멘토 |
| 4 | 계획서·발표의 "경상도·충청도", "A/B/C/D 4종"이 현재 결정(경상도만, A/B/C)과 다름 → 계획서 문구 수정 | 팀 |
| 5 | 마음AI 데이터 시트는 STT 오인식("5븐", "오분")을 LLM 학습 데이터에 섞음 → 우리 STT 오류 결과를 LLM 학습에 넣을지 | LLM 담당 |
| 6 | STT 출력에 문장부호가 없어도 LLM 쪽에 문제 없는지 | LLM 담당 |

## 5. 다음 할 일 (제안)

1. **문장 확장:** 178 → 500~600문장. 기기 × 동작 × 경상도 어미(-노 -나 -도 -래이 -삐라 -제 -데이 -는교 -카이 등)를 체계적으로 조합
2. **실제 녹음:** 팀원 3~4명 × 각 150문장 ≈ 500~600개 — 효과가 가장 클 것으로 예상
3. **평가셋 고정:** 학습에 안 쓰는 100문장 × 화자 2~3명(학습 녹음 안 한 사람 포함)
4. **보드 이식:** `models/sense-voice-ko-tts_a1/`을 보드 `~/voice/models`에 넣고 보드 CPU에서 속도·정확도 재확인
