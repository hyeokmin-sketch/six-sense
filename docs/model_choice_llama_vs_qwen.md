# SIX-SENSE 모델 선택 — Llama가 더 괜찮은 이유

작성: 2026.11.7 · 비교 대상: Llama-3.2-1B-Instruct, Qwen3.5-2B (둘 다 같은 데이터·같은 설정으로 LoRA 파인튜닝)

---

## 결론

**Llama-3.2-1B를 최종 후보로 삼습니다.** 정확도는 Qwen과 거의 같고, 더 작고 빠르며, 글자가 깨진 "해당 없음" 입력에서 엉뚱한 동작을 덜 합니다. 보드(Orange Pi 5 Plus)에 올릴 모델로는 Llama가 유리합니다.

단, 보드에서 양자화(RKLLM W8A8)한 뒤의 성능은 아직 측정하지 않았습니다. 양자화 후에 다시 확인하고 최종 확정합니다.

---

## 1. 비교 표 (같은 학습 데이터 v2dict2 기준)

| 항목 | Llama-3.2-1B | Qwen3.5-2B | 유리한 쪽 |
|---|---|---|---|
| val (400) | 99.5% | 99.8% | 비슷 |
| 50대 평가 (36) | 97.2% | 100% | 비슷 (1문장 차이) |
| 20·30대 v3 (89) | 97.8% | 97.8% | 같음 |
| 사전 holdout (330) | 91.5% | 90.6% | 비슷 |
| STT 오인식 eval_stt_aug (708) | 85.0% | 85.7% | 비슷 |
| 해당 없음 50대검수 조작 오류 | 1/29 | 0/29 | 비슷 |
| 신규 물건 해당 없음 조작 오류 | 0/54 | 0/54 | 같음 |
| **글자 깨진 해당 없음 조작 오류 (eval_stt_aug)** | **1/83** | 5/83 | **Llama** |
| **학습 시간 (T4)** | **약 14분** | 약 27분 | **Llama** |
| **추론 속도 (문장당)** | **0.073초** | 0.162초 | **Llama (약 2배)** |
| **크기** | **약 1.24B** | Llama의 약 1.5배 | **Llama** |

※ 조작 오류 = 실행하면 안 되는 말(해당 없음)에 기기를 조작하는 호출을 내는 경우

---

## 2. Llama를 고른 이유

**① 정확도는 사실상 같습니다.**
val, v3, 사전 holdout, STT 오인식 평가에서 차이가 0.3~1%p 안팎이고, 문장 1~2개 차이입니다. 평가셋이 작아서 우연일 수 있는 수준이라 정확도로는 우열을 가리기 어렵습니다.

**② 글자가 깨진 입력에서 엉뚱한 동작을 덜 합니다.**
STT가 틀린 글자 중 "해당 없음"이어야 하는 83문장에서 Llama는 1개, Qwen은 5개를 기기 조작으로 오인했습니다. 실제 서비스에서는 STT 오류가 흔하기 때문에, 안 시킨 동작이 실행되는 일이 적은 쪽이 중요합니다.

**③ 보드에 올리기에 가볍고 빠릅니다.**
Orange Pi 5 Plus에서 돌려야 하므로 크기와 속도가 직접적인 조건입니다. Llama는 Qwen보다 작고, 같은 환경(T4)에서 문장당 추론이 약 2배 빠릅니다. 음성 입력부터 응답까지의 지연을 줄이는 데 유리합니다.

**④ 학습·반복이 빠릅니다.**
학습이 약 14분이라 데이터를 고치고 다시 학습하는 속도가 Qwen의 약 2배입니다. 이번에 v2dict3를 만들어 하루 안에 평가까지 마친 것도 이 덕분입니다.

**⑤ 출력 형식이 안정적이었습니다.**
Qwen은 정의되지 않은 기기 번호(`object=4`)를 출력한 사례가 있었습니다. Llama는 형식 준수 100%를 유지했습니다. (파서에서 정의되지 않은 호출을 막는 방어는 어느 모델이든 필요합니다.)

---

## 3. Qwen이 더 나은 점 (공정하게)

- 50대 평가 36문장에서 100%로, Llama v2dict2(97.2%)보다 1문장 더 맞혔습니다.
- val이 99.8%로 0.3%p 높고, 해당 없음 50대검수 조작 오류가 0/29였습니다.
- 파라미터가 더 커서, 앞으로 데이터가 크게 늘어나거나 기기·동작이 많아지면 여유가 있을 수 있습니다.

다만 이 차이는 모두 평가셋이 작아서 우연일 수 있는 범위이고, 위의 속도·크기·오작동 차이를 뒤집을 만큼 크지 않습니다.

---

## 4. 현재 최신 상태

Llama는 이후 B 세트를 추가한 **v2dict3**까지 학습하고 평가했습니다.

| 평가 | Llama v2dict2 | Llama v2dict3 |
|---|---|---|
| 실제 50대 녹음 95문장 | 87.4% | **94.7%** |
| STT 오인식 eval_stt_aug | 85.0% | 88.4% |
| 해당 없음 50대검수 조작 오류 | 1/29 | 0/29 |
| val | 99.5% | 99.0% |

Qwen은 v2dict2까지만 측정했고, **Qwen v2dict3는 측정하지 않았습니다.** 위 비교표는 둘 다 v2dict2인 조건입니다.

---

## 5. 한계와 확인할 것

- **양자화 후 성능은 미측정입니다.** 양자화(W8A8)하면 성능이 떨어질 수 있습니다. Llama가 크게 떨어지면 Qwen으로 바꿀 수 있도록 Qwen v2dict2 결과와 어댑터를 보관합니다.
- **평가셋이 작습니다.** 50대 36, 해당 없음 29·54, 실제 녹음 95문장 단위라 몇 문장 차이는 우연일 수 있습니다.
- **Qwen v2dict3는 측정하지 않았습니다.** 필요하면 같은 데이터로 학습해 비교할 수 있습니다 (약 27분).
- **Llama는 Hugging Face 사용 동의가 필요합니다.** 모델을 내려받을 때 약관 동의와 토큰이 필요하고, 제품화할 때는 Llama 3.2 라이선스 조건을 확인해야 합니다.
- **실제 사람 음성 종단 평가는 아직 없습니다.** 실제 녹음 95문장의 STT 결과를 LLM에 넣어 본 것이고, 마이크 입력부터 끝까지의 시연 환경 평가는 하지 않았습니다.
